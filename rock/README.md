# Metal Beast — The Path for the Chosen

An early, free pilot for a dedicated heavy music community. English is the default; Russian, Spanish, French, German, and Portuguese are available in the language menu.

## What works in the pilot

- Filter the subgenre directory by scene.
- Start a community discussion, propose a subgenre, or add a concert listing through GitHub Discussions.
- Reply to posts and react to them on the shared discussion board.

GitHub Discussions is the pilot's shared storage. Writing requires a GitHub account; contributions and the GitHub username are public. The page does not collect email addresses. The concert board intentionally starts empty and has no fabricated events or member counts.

This is an experiment to measure interest, not a finished independent social network. The site is hosted free on GitHub Pages.
